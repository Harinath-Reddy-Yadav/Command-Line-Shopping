# Command Line Shopping

A simple command-line shopping cart application built with Python that allows users to browse products, add/remove items, and generate invoices.

## Features

- **Product Categories**: Electronics, Clothing, and Food items
- **Shopping Cart Management**: Add, remove, view, and update item quantities
- **Invoice Generation**: Create and save invoices with customer details
- **Input Validation**: Validates customer name and phone number
- **Easy-to-use Menu**: Interactive menu-driven interface
